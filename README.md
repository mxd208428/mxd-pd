# mxd-pd - 论文排版 Claude Code Skill

一个用于论文排版的 Claude Code Skill，支持自动检测图表序号、补全图序图题/表序表题、格式化排版等功能。

## 功能特性

- 📝 **交互式排版引导** - 分步询问格式要求，支持数字快速选择
- 📊 **图表序号自动处理** - 检测缺失的图序图题/表序表题，根据上下文自动生成
- 🔢 **序号连续性检查** - 自动检测图/表序号是否跳号或乱序
- 🖼️ **图片行距修复** - 自动处理固定行距下图片显示不全的问题
- 📋 **表格跨页断行** - 支持表格跨页显示，表头重复
- ✅ **格式检查模式** - 只检查不修改，输出问题清单
- 🎨 **排版模式** - 自动修改格式，生成新文件

## 安装

将 `mxd-pd` 文件夹复制到 Claude Code 的 skills 目录：

```bash
# Windows
copy mxd-pd %USERPROFILE%\.claude\skills\

# macOS/Linux
cp -r mxd-pd ~/.claude/skills/
```

## 使用方法

在 Claude Code 中输入：

```
/mxd-pd
```

然后按照交互式引导操作：

```
1. 选择任务类型（排版/检查）
2. 提供论文文件路径
3. 选择是否有规范文件
4. 设置格式要求（字体、字号、行距等）
5. 确认并执行
```

### 示例

```
/mxd-pd 排版论文.docx
/mxd-pd 检查论文.docx
```

## 支持的格式选项

### 标题格式
- 字体：黑体、宋体、仿宋、楷体
- 字号：三号、小三、四号、小四、五号
- 编号：理工类（1.→3.1→3.1.1）、文史类（一、→（一）→1.→（1））

### 正文格式
- 字体：仿宋、宋体、楷体
- 字号：四号、小四、五号
- 行距：固定值24磅、28.8磅、20磅、1.5倍行距

### 图表格式
- 图题/表题字体字号
- 表格内容字体字号
- 图注/表注位置

## 自动处理机制

### 图片行距修复
固定行距会导致嵌入式图片显示不全，skill会自动将图片段落设为单倍行距。

### 图表序号检测
- 检测图片是否有图序图题（图1 xxx）
- 检测表格是否有表序表题（表1 xxx）
- 检查序号是否连续
- 根据上下文自动生成缺失的标题

### 表格跨页断行
- 允许表格跨页显示
- 支持表头在跨页时重复显示

## 技术实现

基于 `python-docx` 库，主要功能：

```python
# 图片段落行距处理
fix_image_paragraphs(doc)

# 图表序号检测与补全
fix_figure_table_captions(doc, figure_format, table_format)

# 表格跨页断行
set_table_allow_break(table)
set_table_header_repeat(table)
```
